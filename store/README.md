# App Store submission material (SPEC 11.6)

- `metadata/en-US/` — fastlane `deliver`'s standard metadata layout: name, subtitle, description,
  keywords, promotional text, support/privacy/marketing URLs, release notes.
- `metadata/review_information/` — App Review's contact details and reviewer notes. `first_name.txt`,
  `last_name.txt` and `phone_number.txt` are still `PASTE-*` placeholders — fill them in via `OWNER.md`
  before the first `store-<n>`/`submit-<n>` push (App Store Connect requires a real reviewer contact).
- `AGE_RATING.md` — the age rating questionnaire's answers, since `deliver` doesn't automate that survey
  reliably across API versions; answer it by hand in App Store Connect (or against its API) using this.
- `copyright.txt`, `primary_category.txt`, `primary_first_sub_category.txt` — the remaining App Store
  Connect listing fields `deliver` can set directly.
- `Fastfile` — a minimal marker (see its own comment) so `.github/workflows/store.yml` actually attempts
  the upload once Apple secrets exist, instead of skipping.
- `screenshots/` — empty for now. SPEC 11.6/STYLE.md 13 call for 5 portrait screenshots generated by
  Playwright from scripted game states at the size Apple currently requires for the largest iPhone, each
  with a specific caption. Not built yet — needs its own scripted-state Playwright pass, separate from
  `e2e/screenshots.spec.ts`'s gate-8 review screenshots (which are unstyled and the wrong aspect/size for
  App Store submission).
